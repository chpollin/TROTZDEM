    Wie das entstanden ist

    Alles auf dieser Seite ist mit generativer KI entstanden. Die Songs hat Suno erzeugt (Modell v5, 2025). Die Texte hat Claude Opus geschrieben, Christopher Pollin hat sie zusammengesetzt und gepromptet. Die Videos sind vollständig aus Code gerendert, ohne Bild- oder Videomodell. Den Code hat Claude Opus 5.5 in Claude Code geschrieben, ebenso diese Seite.

    Für jedes Video hat Claude Opus 5.5 als Agent in Claude Code zuerst die Stimme von der Musik getrennt, den Text mit einem Spracherkennungsmodell auf die Aufnahme gelegt und den Takt gemessen. Dann entstand die Szene als Programm, das jedes Einzelbild aus der Zeit berechnet, und ein Browser hat sie Bild für Bild gerendert. Einzelne Entwürfe hat ein zweiter, unabhängiger Agent geprüft, seine Kritik floss in die Überarbeitung.

    Umgesetzt wurde das mit Context Engineering und Agentic Engineering, und trotzdem ist alles zu 100 Prozent vibe coded.

    Christopher Pollin, Graz, 2025–2026. Quellcode auf GitHub (Code unter MIT-Lizenz).
