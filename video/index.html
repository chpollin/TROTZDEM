    Wie das entstanden ist

    Alles auf dieser Seite ist mit generativer KI entstanden. Die Songs hat Suno erzeugt (Modell v5, 2025). Die Texte hat Claude Opus geschrieben, Christopher Pollin hat sie zusammengesetzt und gepromptet. Die Videos sind vollständig aus Code gerendert, ohne Bild- oder Videomodell. Den Code hat Claude Opus 5.5 in Claude Code geschrieben, ebenso diese Seite.

    Christopher Pollin, Graz, 2025–2026. Quellcode auf GitHub (Code unter MIT-Lizenz).
