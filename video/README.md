# TROTZDEM videos

Music videos for the songs of the TROTZDEM playlist, rendered entirely from code. Each song is staged in one interface, without real brands or product UI: "Neunundachtzig Tabs" plays inside a browser window, the others in their own terminal, chat, editor or chart. Lyrics are set in Redaction, whose damage grades carry decay and restoration across the series, with Space Mono for interface text.

## Layout

- `player.html?song=<folder>` plays a song's scene live with audio (click or space to play, arrow keys seek, `&t=40` starts at 40 s) and, with `&render=1`, exposes `renderFrame(t)` for the renderer.
- `<folder>/scene.js` is the whole video as `drawScene(ctx, t)`, a pure function of time, plus `SCENE_END` and optionally `SCENE_TITLE` and `SCENE_FONT_FACES` (extra fonts from the song's own folder).
- `<folder>/timeline.js` holds section and line onsets; `<folder>/analysis.js` holds loudness, onsets and vocal loudness, generated by `tools/analyze.py`.
- `<folder>/source/` (not versioned) holds the downloaded audio, the separated stems, the lyrics and `timing-report.md`; `<folder>/out/` (not versioned) holds stills and renders.
- `songs.json` maps folders to Suno clip ids.
- `fonts/` vendors Space Mono and Redaction (SIL Open Font License, see the license files).

## Preparing a song

`tools/prepare.py` downloads a song from the playlist, separates the vocals, force-aligns the written lyrics, transcribes what is actually sung, finds vocal phrase starts and the tempo, and writes `source/timing-report.md` and `analysis.js`. It needs a separate venv with CUDA torch:

```
python -m venv .venv
.venv\Scripts\python -m pip install torch==2.8.0 torchaudio==2.8.0 --index-url https://download.pytorch.org/whl/cu128
.venv\Scripts\python -m pip install stable-ts "audio-separator[gpu]"
.venv\Scripts\python -m pip install --force-reinstall --no-deps torch==2.8.0 torchaudio==2.8.0 --index-url https://download.pytorch.org/whl/cu128
.venv\Scripts\python tools/prepare.py sycophancy
```

torch is pinned to 2.8 because later torchaudio releases route audio I/O through TorchCodec, which breaks the separation tools on Windows. The second torch install is needed because stable-ts pulls a CPU-only torch over the CUDA build.

The aligner stretches the first word of some lines. Onsets in a `timeline.js` are therefore checked against the free transcription and the vocal phrase starts in the report; where they disagree, the phrase start wins.

Suno's terms allow commercial use only of output downloaded through Suno's official download on a paid plan. The audio used here is taken from Suno's public clip video. Before publishing, replace `<folder>/source/audio.wav` with the official download (same length expected) and render again.

## Preview and render

```
python -m http.server 8089 --bind 127.0.0.1           # then open http://127.0.0.1:8089/player.html?song=neunundachtzig-tabs
python tools/render.py neunundachtzig-tabs --still 36 52.5
python tools/render.py neunundachtzig-tabs --phone    # out/<folder>.mp4 at 1920x1080, 30 fps, plus a 720p copy
```

## Neunundachtzig Tabs

The browser window is the stage: tabs open on the drum hits, the strip compresses from titles to favicons to slivers, "Wie lösche ich mich selbst" stands still without colour or results, every tab gets its own vanishing point, the window contains itself, and in the bridge the 89 tabs leave the window and pile up into the tower of the single cover. In the spoken end the sentence stacks itself into a tower of rows that restores but never becomes clean, until the hard stop.
