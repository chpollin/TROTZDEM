# Neunundachtzig Tabs

Music video for the TROTZDEM track "Neunundachtzig Tabs", rendered entirely from code. The browser window is the stage: tabs open on the drum hits, the strip compresses from titles to favicons to slivers, the window contains itself, and in the bridge the 89 tabs leave the window and pile up into the tower of the single cover. The lyric layer is set in Redaction, whose damage grades carry the decay of the song and, in the spoken end, its restoration.

## Files

- `index.html` plays the scene live with audio (click or space to play, arrow keys seek, `?t=40` starts at 40 s) and, with `?render=1`, exposes `renderFrame(t)` for the renderer.
- `scene.js` is the whole video as `drawScene(ctx, t)`, a pure function of time.
- `timeline.js` holds section and line onsets.
- `analysis.js` holds loudness and onsets, generated by `analyze.py`.
- `align.py` separates the vocals and force-aligns the lyrics to refine `timeline.js`.
- `render.py` renders frames in parallel browser processes and muxes the MP4.
- `fonts/` vendors Space Mono and Redaction (SIL Open Font License, see the license files).

## Source audio

`source/` is not versioned. For local work the audio is taken from Suno's public clip video:

```
curl -o source/suno.mp4 https://cdn1.suno.ai/fd6027fc-f986-464c-81b3-5fc76d8f9e92.mp4
ffmpeg -i source/suno.mp4 -vn -ac 2 -ar 48000 source/audio.wav
python analyze.py
```

Suno's terms allow commercial use only of output downloaded through Suno's official download on a paid plan. Before publishing, replace `source/audio.wav` with that download (same length expected) and render again.

## Preview and render

```
python -m http.server 8089 --bind 127.0.0.1    # then open http://127.0.0.1:8089/
python render.py --still 36 52.5               # inspection frames in out/
python render.py                               # out/neunundachtzig-tabs.mp4, 1920x1080, 30 fps
```

## Lyric alignment

`align.py` needs a separate venv with CUDA torch, because it runs a vocal separation model and Whisper large-v3:

```
python -m venv .venv
.venv\Scripts\python -m pip install torch==2.8.0 torchaudio==2.8.0 --index-url https://download.pytorch.org/whl/cu128
.venv\Scripts\python -m pip install stable-ts "audio-separator[gpu]"
.venv\Scripts\python -m pip install --force-reinstall --no-deps torch==2.8.0 torchaudio==2.8.0 --index-url https://download.pytorch.org/whl/cu128
.venv\Scripts\python align.py
```

torch is pinned to 2.8 because later torchaudio releases route audio I/O through TorchCodec, which breaks the separation tools on Windows. The second torch install is needed because stable-ts pulls a CPU-only torch over the CUDA build.

The aligner stretches the first word of some lines. The onsets in `timeline.js` were therefore checked against a free transcription of the vocal stem and against its phrase starts; where they disagree, the phrase start was taken.
