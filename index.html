    Wie das entstanden ist

    Die Songs sind in den letzten zwei Jahren entstanden, als persönliche Auseinandersetzung mit agentischer KI. Sie sind vollständig KI-generiert. Die Musik stammt von Suno (Modell v5), die Texte von Claude Opus, auf Grundlage meiner Prompts und Überlegungen und ergänzt um Ergebnisse von Deep-Research-Modellen. Auswahl, Zusammenstellung und Prompting stammen von mir.

    Die Videos sind vollständig aus Code entstanden, ohne Bild- oder Videomodell. Jedes Video ist ein JavaScript-Programm, das jedes Einzelbild als Funktion der Zeit auf eine Zeichenfläche malt. Geschrieben hat es Claude Opus 5.5 in Claude Code, und der Code jedes Videos ist auf GitHub einsehbar. Python übernimmt alles drumherum. Es trennt die Stimme von der Musik, legt den Text per Spracherkennung auf die Aufnahme, misst den Takt und lässt einen Browser das Programm Bild für Bild rendern, ffmpeg setzt die Bilder zum Video zusammen. Ein zweiter Agent hat einzelne Entwürfe geprüft. Auch diese Seite ist so entstanden, mit Context Engineering und Agentic Engineering und zugleich vollständig vibe coded. Die Videos dokumentieren damit auch, was aktuelle Modelle beim Programmieren leisten.
